Z-Score & Std. Deviasi

RUMUS UTAMA
z = x − μ σ
Z-Score menunjukkan seberapa jauh suatu nilai menyimpang dari rata-rata, diukur dalam satuan standar deviasi.
Standar Deviasi Populasi (σ)
σ = √ Σ(xᵢ − μ)² N
Standar Deviasi Sampel (s)
s = √ Σ(xᵢ − x̄)² n − 1
z = z-score x = nilai data μ / x̄ = rata-rata σ / s = standar deviasi N = banyak data populasi n−1 = derajat kebebasan sampel
